Changelog

Every shipping moment, in reverse chronological order. Built in public.

v4.5.2 — 24 April 2026

Cross-app moat closed. Slack Web + Microsoft Teams Web added to the auto-fill loop. Pipedrive + Salesforce CRM integrations live. Klosr Desktop + Watch finalized. Public marketing site shipped.

  • 🔌 Slack Web auto-fill — Klosr drafts in PWA Watch, you click 📤 Slack, the composer auto-fills on your Slack tab.
  • 🔌 Microsoft Teams Web auto-fill — same pattern, Teams composer.
  • 📤 Cross-tab Chrome notifications — when a pending draft lands and you're not on that tab, OS notification fires so you know to switch over.
  • 📊 Pipedrive integration — paste your API token, Klosr pushes deals as Person + Org + Deal in one atomic flow.
  • 🗂️ Salesforce OAuth — full scaffold + callback handler. Connected App on the admin side, then one-click connect, deals push as Leads.
  • 🧩 HubSpot OAuth callback — completes the integration that was scaffolded in v4.5.0.
  • 🖥️ "Klosr Desktop (Watch)" chip in the Chrome extension sidebar — discoverability fix; one-click open + install ID copy.
  • 📣 Public marketing site — landing, pricing, install, privacy, terms, changelog. Domain alias coming next.

v4.5.1 — 23 April 2026

Klosr Watch evolves. Cross-app reply auto-fill (WhatsApp Web + Gmail). State sync extension → Upstash → PWA so Watch drafts use your real proof + voice. Anti-throttle keepalive so Watch survives backgrounded tabs.

  • 📤 WhatsApp Web auto-fill — extension content script picks up pending replies queued by PWA Watch, auto-fills the WhatsApp composer.
  • 📤 Gmail auto-fill — same pattern for Gmail web compose / reply panes.
  • 🔄 State sync — Chrome extension pushes proof library + objection playbook + voice examples + ICP learnings to Upstash. Klosr Desktop pulls them in pwa-bootstrap. Watch drafts now feel like YOU wrote them.
  • ⚡ Anti-throttle — Watch uses Web Audio keepalive + Wake Lock to survive Chrome's background tab throttling. Runs while you work.
  • 📊 Pending-reply queue actions: queue-pending-reply + fetch-pending-reply with 5-min TTL.

v4.5.0 — 23 April 2026

Two huge moves: Klosr Vision (multimodal screenshot paste) and Klosr Desktop (PWA, installable as a native-like app). Scaffolded HubSpot, Slack webhook, weekly brag-post generator. Foundation for cross-platform reactive Klosr.

  • 👁️ Klosr Vision — paste any screenshot (WhatsApp, email, Slack, anywhere), Claude Sonnet 4.5 reads it, drafts the action. Both in extension and PWA.
  • 🖥️ Klosr Desktop (PWA) — installable web app. Standalone window, dock/taskbar icon, lives outside the browser tabs.
  • 🔥 Weekly brag-post generator — turn your week's numbers into a LinkedIn post drafted in your voice.
  • 🧩 HubSpot OAuth + push-deal — scaffold (callback page came in v4.5.2).
  • 💬 Slack incoming-webhook integration — paste a webhook URL, alerts go to your channel.
  • 🧠 Sonnet 4.5 → Opus 4.7 upgrade for screenshot-analyze, weekly-brag-post, deal-revival-draft (the three high-stakes outputs).

v4.4.0 — 22 April 2026

The "let me actually close this" release. One-click LinkedIn DM send, hot-reply Chrome notifications, auto-scheduled day-4 + day-9 follow-ups.

  • 📤 One-click "Send via Klosr" on warm-lead cards. Auto-fills LinkedIn's native message composer.
  • 🔔 Hot-reply Chrome notifications — content script on linkedin.com/messaging fires native OS notifications when a pipeline contact replies.
  • 📅 Auto-scheduled follow-ups — every DM sent → day-4 + day-9 commitments auto-created in Daily Close. No more "I forgot to follow up".

v4.3.0 — 23 April 2026

Daily Close Dashboard. Deal temperature scoring. The "what do I do today to close" reorientation.

  • ⚡ Daily Close Dashboard — top 12 ranked actions, money KPIs, deal temperature distribution, hot deals list.
  • 🌡️ Deal temperature — every deal scored hot/warm/cold/frozen with reason. Visible on every pipeline card.
  • 🧊 Revive button — auto-drafts re-engagement messages anchored to fresh company news (SerpApi).
  • 👥 Multi-thread suggestions — late-stage deal? Klosr finds 2-4 other decision-makers at the same company via Apollo.
  • 📥 Enhanced handle-reply — adds temperature, urgency, suggestedProof from your library.
  • 📊 "Already in pipeline" badge on warm leads to prevent duplicate work.

v4.2.0 — 21 April 2026

Klosr deal pipeline rebuilt around closing. Removed interview/pitch modes. Won deals → proof library. Stuck-deal alerts.

  • 📊 Deal Pipeline view — stages, commitments with dueBy, won/lost tracking, weighted revenue.
  • 👻 Auto-ghost stale deals — 14d+ silent deals auto-flagged.
  • 🔑 Won deal → proof library extraction — Claude pulls out reusable proof points from your closing notes.
  • 🚨 Stuck-deal alerts — negotiation 14d+, closing 7d+, objection 10d+.
  • 📅 Inline due-date editor on commitments.

v4.1.0 — 20 April 2026

  • 📚 Full Dossier ("Know them cold") with Spanish + bold-markdown + 11 sections + cache.
  • 🎤 Live Assist evolved — diarization (speaker separation), talk-ratio bar, 12-signal coach, 1Hz gated coach loop.
  • 📞 Apollo replaces LeadMagic for email + phone discovery.
  • 📊 Admin panel with Upstash-backed user analytics + event log.

v4.0.0 — 18 April 2026

  • 📞 Live AI Assist on Meet/Zoom/Teams calls — Deepgram Nova-3 streaming + Claude coach.
  • 🤝 Warm Leads tab with ICP scoring, mutual connections, bulk actions.
  • 🧠 Initial Klosr Vision research mode.

What's coming

Roadmap. Things we're actively building or scoping:

  • Native Tauri desktop app — replaces the PWA. Menu bar / system tray. Reads native WhatsApp Desktop / Slack Desktop / etc. without the browser screen-share banner. Auto-injects text directly into native composers via OS accessibility APIs. Target: 4 weeks. Pro users get it free.
  • Salesforce token refresh — currently tokens expire after 15min-2h, user reconnects. Auto-refresh in v2.
  • Bi-directional HubSpot sync — pull existing deals/contacts from your portal into Klosr pipeline.
  • Full Slack OAuth app (vs. webhook) — slash commands, interactive buttons, thread-replies. Pending Slack App Directory submission.
  • Gmail / Outlook native OAuth — move email beyond Vision into native read+send. Long lead time (Google Workspace + Microsoft Graph review).
  • Klosr for Teams SKU — multi-seat workspace, shared playbooks, admin-level analytics.
  • Public Chrome Web Store listing — currently beta-distributed via zip, going public after pre-launch shake-out.
