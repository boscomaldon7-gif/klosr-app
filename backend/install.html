Install Klosr in 60 seconds.

Two pieces — Chrome extension (LinkedIn + calls) and Klosr Desktop (every other app). Install both. Works offline-first; no signup required.

1

Install the Chrome extension

Klosr's brain. Lives on LinkedIn profiles, Meet/Zoom/Teams calls, WhatsApp Web, Gmail, Slack, Teams web. Auto-fills replies, tracks deals, runs Live Assist on demos.

  • Download the latest build → klosr-4.5.2.zip (or get from your Klosr admin)
  • Unzip the folder anywhere
  • Open Chrome → chrome://extensions → toggle Developer mode ON (top-right)
  • Click Load unpacked → pick the unzipped folder
  • When Klosr asks for notification permission later, click Allow

🪐 Coming soon: one-click install via Chrome Web Store (in review).

2

Onboard on LinkedIn

Open any LinkedIn profile (yours or anyone's). The Klosr sidebar slides in. Click Onboarding and fill in:

  • What you sell — one paragraph, founder voice. This is the most important field. Klosr cites this in every draft.
  • Your ICP — who you sell to (industry, role, stage, geography). Klosr filters warm leads against this.
  • 3-5 proof points — your real customer wins with names and numbers. Klosr cites these in objection rebuttals.
  • Voice tone — direct/founder-mode, not enterprise-speak. Klosr mirrors it.

Done? Klosr now generates briefs, dossiers, drafted replies — all in your voice with your proof.

3

Install Klosr Desktop (PWA)

The Watch mode — Klosr reads your screen, drafts replies in real time across every app. Not just web — anything visible on your screen.

  • Open Klosr Desktop
  • In Chrome's address bar, click Install app (the small download icon on the right side)
  • Klosr Desktop now has its own dock/taskbar icon — runs like a native app
  • Open the Chrome extension on any LinkedIn profile → click the 🖥️ Klosr Desktop (Watch) chip → copy your Install ID → paste into Klosr Desktop → Connect
🖥️ Open Klosr Desktop →
4

Start Watching (the magic moment)

In Klosr Desktop, click ▶ Start watching. Chrome shows a screen-share picker. Pick:

  • Entire screen — Klosr sees every app, including WhatsApp, Slack, Gmail, Sales Nav, anything
  • A specific window — e.g. just your WhatsApp Desktop window
  • A browser tab group — e.g. just your work tabs

From now on: every reply that arrives gets seen by Claude Opus 4.7 within 4 seconds. Drafted in your voice. Ready to send with one click.

5

Optional: connect your CRM + Slack

Klosr can push every closed deal into HubSpot, Pipedrive, or Salesforce. Slack alerts on hot replies. Open Klosr Desktop → ⚙️ Integrations:

  • HubSpot — OAuth one-click. Pushes contact + deal with stage mapping.
  • Pipedrive — paste your API token. Pushes Person + Org + Deal.
  • Salesforce — OAuth. Pushes as Lead with source: Klosr.
  • Slack — paste your incoming-webhook URL. Hot-reply alerts go to your team channel.

That's it. Now go close some deals.
