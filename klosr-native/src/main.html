Release notes for v0.3.0 April 26, 2026

Welcome to Klosr 0.3

Klosr 0.3 ships a brand-new main app window alongside the floating capsule, Cluely-style onboarding, full settings, billing, and a complete sessions history. Built so founders can manage Klosr like a real product, not just a floating helper.

A few standout improvements

  • Two-window architecture. The capsule keeps doing the typing; the new main app handles onboarding, billing, integrations, and history.
  • Unicode keystroke injection (v0.2.1) — auto-paste now works on WhatsApp Desktop, Slack, Discord, Outlook, Teams. SendInput types each character; Electron apps treat it as real keyboard input.
  • Foreground tracking. Hovering an inject button captures the target HWND; click forces SetForegroundWindow + types. Always lands in the right app.
  • Dashboard with stats — drafts, sends, watch time, hot replies. Persisted day-by-day in localStorage.
  • Settings sidebar with General / Profile / Keybinds / Security / Language / Billing.
  • Pricing page with Pro ($13.99/mo) and Team ($79.99/seat/mo) plans, both deep-linked to Stripe Checkout via the backend.

Coming next

  • Calendar integration (Google + Outlook) — auto-pull meetings into the Sessions list
  • Macros / Keybinds — set Ctrl+Shift+W for "draft + send to WhatsApp" without leaving the keyboard
  • Klosr Teams workspace — shared proof library, voice profile, ICP across seats
